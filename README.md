# SXCRED

Русскоязычное портфолио с манга-композицией, оригинальными анимациями и полноэкранным просмотром проектов.

## Запуск

Требуется Node.js 22.13 или новее.

```sh
npm install
npm run admin:password
npm run db:migrate:local
npm run dev
```

Адрес локального просмотра: http://localhost:3000.

```sh
npm run typecheck
npm run lint
npm run build
```

`lint` проверяет код сайта. `lint:all` дополнительно проверяет поставляемые шаблоном компоненты `components/ui` и `hooks`; у них есть исходные замечания линтера. Поставляемые компоненты сохранены без изменений.

## Добавить работу

1. Откройте `/admin` и введите пароль из локального файла `.admin-password.local.txt`.
2. Нажмите «Добавить работу», заполните название и категорию.
3. Перетащите изображения или видео: JPG, PNG, WebP, GIF, MP4, WebM, до 25 МБ на файл и до 20 файлов в работе.
4. Выберите обложку кнопкой «На обложку»; стрелки меняют порядок галереи. Год, клиент и описание необязательны.
5. Сохраните черновик или опубликуйте работу. Изменения опубликованной работы появятся на сайте после «Обновить на сайте» и обновления открытой страницы портфолио.

Черновики и их файлы доступны только администратору. «Снять с публикации» снова скрывает работу. Удаление работы убирает её из списка и с сайта; сами файлы остаются закрытыми в хранилище. В панели есть подтверждение удаления и предупреждение о несохранённых изменениях.

Записи хранятся в D1 (`DB`), файлы — в R2 (`MEDIA`). Локальные данные находятся в `.wrangler/state`; опубликованный сайт использует отдельные хранилища. Локальные тестовые загрузки не переносятся на сервер автоматически. `data/projects.ts` содержит стартовые обложки: они показываются, пока в базе нет опубликованных работ.

### Пароль и запуск на сервере

`npm run admin:password` создаёт случайный пароль и записывает его только в игнорируемый локальный файл. В `.dev.vars` хранится соль и хеш PBKDF2-SHA256 (100 000 итераций). Не публикуйте эти файлы. Для смены пароля: `npm run admin:password -- --rotate`. Свой пароль можно передать через переменную `SXCRED_NEW_PASSWORD` (14–256 символов), без аргументов командной строки.

Для опубликованного сайта установите секрет `ADMIN_PASSWORD_HASH` в Sites из `.dev.vars`, затем разверните новую версию. После смены хеша старые сессии перестают действовать. При отсутствии секрета панель остаётся закрытой. Сессия действует 12 часов, cookie — HttpOnly/SameSite=Strict и Secure на HTTPS; мутации проверяют Origin, вход ограничен пятью попытками за 15 минут на IP.

Миграции создаются `npm run db:generate`, применяются локально `npm run db:migrate:local`; опубликованные миграции применяет Sites. Проверка полного серверного сценария: `node scripts/verify-admin.mjs` при работающем локальном сервере. Она создаёт временную работу и удаляет её после проверки.

### Формат стартовых данных

Для редактирования демонстрационных обложек используйте `data/projects.ts`:

```ts
{
  id: 'my-project',
  title: 'Название работы',
  category: 'DOTA 2 / ПРЕВЬЮ',
  year: '2026',
  client: null,
  description: 'Описание проекта.',
  images: [
    { src: '/projects/my-cover.webp', alt: 'Описание первого изображения' },
    { src: '/projects/my-detail.webp', alt: 'Описание второго изображения' },
  ],
  placeholder: false,
  layout: 'featured',
  art: 'dota',
  coverText: 'NEXT\nLEVEL',
}
```

`layout`: `featured`, `portrait`, `wide`, `compact`. Проекты используют адаптивную сетку; на мобильном они расположены вертикально. `art` и `coverText` определяют вид заглушки, если изображений пока нет. `id` должен быть уникальным. Год и клиент необязательны, неуказанные значения не отображаются. Ссылка `#project/my-project` открывает проект в той же странице.

## Клиенты и контакты

- `data/clients.ts`: никнеймы, аватары, тип работ, необязательные ссылки.
- `data/site.ts`: все основные тексты, услуги, контакты и навигация.
- Контакт с `url: null` отображается как «Скоро». Для email используйте `mailto:адрес`.
- Указаны только предоставленные имена: blindzonexgod, mangekyou, Uniquee.

Пока работы и контакты демонстрационные, индексация отключена в `app/layout.tsx`. После наполнения реальным контентом измените `robots` на `{ index: true, follow: true }`.

## Медиа и движение

В `public/media` находятся облегчённые копии трёх исходных файлов из родительской папки `assets`. Оригиналы сохранены. Персонаж использует H.264 без звука, с faststart и воспроизведением вперёд/назад для плавного стыка. Кот использует `cat-transparent.webp`: анимацию с настоящим альфа-каналом, без белого фона и без режима смешивания multiply. Цвет кота и белые детали внутри силуэта сохранены. При паузе показывается `cat-transparent-poster.webp`. Скрипт `scripts/make-cat-transparent.py` воспроизводит обработку исходного видео с помощью FFmpeg, Pillow и NumPy. Шрифты Manrope и Oswald с кириллицей хранятся локально в `public/fonts`; лицензии лежат рядом.

Видео запускаются только рядом с видимой областью, при сворачивании вкладки приостанавливаются. Кнопка паузы останавливает видео и проезд кота. Системный `prefers-reduced-motion` отключает движение. Галерея поддерживает Escape, стрелки клавиатуры, горизонтальный свайп, кнопку браузера «Назад» и удержание фокуса внутри диалога.

## Структура

- `app`: страница, метаданные, общие стили.
- `components/portfolio`: разделы сайта, видео, обложки, галерея.
- `components/ui`: базовые компоненты шаблона; используется доступный диалог Base UI.
- `data`: контент.
- `public`: медиа и шрифты.

Стек: React, TypeScript, Vinext/Vite, Tailwind CSS, Base UI. Движение реализовано через CSS и IntersectionObserver, без постоянных обновлений React при прокрутке.
